# Learning Documentation

Learning documentation is a required product-development deliverable, not an optional summary.

Start with the continuously maintained [AI Assist Work Glossary](GLOSSARY.md) for abbreviations and unfamiliar technical terms.

It will explain what was built, why each tool was selected, how components interact, how macOS capabilities and permissions work, how to inspect relevant code, how to validate behavior, and how problems were diagnosed.

```text
architecture/       System concepts and component relationships
tools/              Tools, libraries, and development workflows
integrations/       Local integrations and their boundaries
macos/              macOS features, permissions, and operations
troubleshooting/    Problems, evidence, diagnosis, and resolution
phase-notes/        Learning record produced by each phase
```

All explanations intended for the learning process will be written in English unless the user explicitly requests otherwise.
