# Project Contracts

This directory contains detailed, versioned contracts adopted by project decisions.

An EDR explains why a decision exists. A contract defines the exact structure that implementation phases must produce. Material contract changes require a new version and an EDR amendment or superseding EDR after the current EDR set is accepted.
